Featured: whisper-rs [crate · repo · docs]

Still the most-downloaded speech recognition crate in Rust, and the one most projects reach for first: whisper.cpp bindings with a small API and every GGML quantization. Two things a reader has to know. It moved to Codeberg in 2025-07 in a declared anti-generative-AI migration, so the GitHub mirror shows as archived and is not evidence of death. And it is pinned to whisper.cpp v1.8.3 while upstream has moved on, with open issues stacking up and no recent commits — so it is no longer the automatic default. For a maintained multi-model engine look at transcribe-rs or sherpa-onnx.

Safety, privacy & supply chain partial

Keeping models and agents from leaking, lying or shipping malware. The supply-chain half is adoptable today — a Rust weights format took the pickle attack surface off the table, and PyTorch has since changed its own defaultSource 1: PyTorch — while the model-facing half is gaps rather than categories.

  1. PyTorch — the incumbent, conceding the point in its own docs

Featured: safetensors [crate · repo · docs]

The de-facto model weight format, and Rust is its reference implementation. Its contribution is structural rather than performance: the format is a JSON header plus raw tensor bytes with no code path, which is what removed the pickle deserialization attack surface that the entire Python model-scanning industry exists to inspect. Loading is zero-copy and memory-mappable, and every Rust framework here reads it. Repository moved from huggingface/safetensors.

Provides functions to read and write safetensors which aim to be safer than their PyTorch counterpart. The format is 8 bytes which is an unsized int, being the size of a JSON header, the JSON header refers the dtype the shape and data_offsets which are the offsets for the values in the rest of the file.
