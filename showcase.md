Everything else on this site is a catalog of things you can `cargo add`. This page is not. These
are significant products and projects with Rust cores — an agent, an editor, a terminal, a dictation app, a manga
translator — and they are here because "who actually ships AI software in Rust?" is a fair question.

**AI that generates Rust is a different subject.** Much of the "AI and Rust" writing in circulation
is about coding agents, proof generation and vibe-coded UIs. This site is about machine learning
*implemented* in Rust. Conflating the two is how a Rust ML list ends up recommending a code
assistant as a tensor library — Codex CLI is below as a large Rust application, not as a tool to
write Rust with.
