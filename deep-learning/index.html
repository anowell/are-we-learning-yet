Deep Learning & Training

Pure-Rust training means Burn; candle can train but is strongest at inference, and tch binds libtorch. Everything else here is historic or a one-maintainer experiment.

Where the community lands is that training stays where the ecosystem already isSource 1: users.rust-lang.org. What Rust offers is the other end of the job: a training binary with no Python runtime inside it.

Deep learning frameworks partial

Defining a model in Rust and training it there. The segment is one full-featured framework deep, and that framework's own book is candid about the gaps that remain.Source 1: Tracel AI

  1. Tracel AI — the project admitting its own gap

Featured: burn [crate · repo · docs]

The only pure-Rust framework that trains as well as it infers, and the one place a Rust-first training story exists at all: one model definition compiled to CUDA, ROCm, Metal, Vulkan, WebGPU or CPU through CubeCL, with no Python runtime in the deployed artifact. It is the right starting point if you want to train in Rust, or if single-binary deployment and non-NVIDIA hardware matter more to you than ecosystem breadth. It is the wrong one if you need pretrained weights, PEFT or multi-node training, none of which exist here yet — for those, train in Python and run the result through ort or tract. No end-to-end training benchmark against PyTorch has been published; the numbers Tracel publishes are op-level against LibTorch.

Featured: candle-core [crate · repo · docs]

Hugging Face's minimalist framework, and the one most Rust model code is actually written against — well over a hundred model examples, CUDA and Metal kernels, GGUF and safetensors loading, and a small enough surface that reading it is a reasonable way to learn it. It is strongest at inference: mistral.rs, Kyutai's Moshi, kalosm, Crane and koharu are all built on it, and its own examples are almost entirely inference rather than training. If you need a training loop with metrics and checkpointing, that is Burn; if you need to write the decode loop yourself and want it small, this is the one.
